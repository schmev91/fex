# Fex - The Trader's Companion

Fex is a sleek, modern, and efficient toolkit for traders, providing essential calculators to manage positions and track trading performance.

## Features

- **Position Size Calculator**: Easily calculate the optimal position size based on account balance, risk percentage, and stop loss distance. Includes "Reverse Mode" to calculate risk from a known lot size.
- **Pip Value Calculator**: Determine the value of a pip for different instruments based on contract size and exchange rates.
- **Trade Journal**: Log your trades to track your performance and history.
- **Dark Mode Support**: Seamless integration with a toggleable dark/light theme (defaults to dark).
- **Responsive Design**: Built with TailwindCSS for a polished, mobile-friendly experience.

## Tech Stack

- **React** (TypeScript)
- **Vite** (Build Tool)
- **Zustand** (State Management)
- **TailwindCSS** (Styling)
- **Decimal.js** (Precise Math)
- **Lucide React** (Icons)

## Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/schmev91/fex.git
   cd fex
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

## Deployment

This project is configured for deployment to GitHub Pages.

1. **Build and Deploy**:
   ```bash
   npm run deploy
   ```
